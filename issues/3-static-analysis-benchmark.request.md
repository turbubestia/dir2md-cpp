# Static Analysis Benchmark

The folder `docs\internal\backend\core` has serveral markdown document generated by different models following the prompt `.github\prompts\static-analysis.prompt.md`. The filename has the format `settings_manager-{model}.md`. Note the model `Qwen3.6-35B-A3B` was run locally with llama.cpp, while all other from the VS Code AI Chat model picker.

The analysis is based on the code in `src\backend\core\settings_manager.hpp/.cpp`, so use it to understand the context of the per-model analyses.

## Goals 
- This task needs to rank these analysis to find out how each model perform in this task.
- Focus only on the findings and edivences in the section `# Static Analysis and Security`, we only whant to know how good the models are to spot bug and security issues.
- Compare the findings of each model and register per model the total finding, common finding almost every other model found, and unique finding no other model found.
- Write a table with the columns: Model, Total, Common, Unit.
- Per model write a list with the each model finding. Each point is a single line. No further explanation of each finding is required. Next if the format
    - Model: {model name}
        - Finding 1 (common|unique) : {one line description}
        - Finding N (common|unique) : {one line description}

- The last section rank (based on finding count and accuracy) the models in a leaderboard table (there are 15 models). Break ties based on the code analysis quality give before the `# Static Analysis and Security` section.
